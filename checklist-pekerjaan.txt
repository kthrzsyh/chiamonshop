# Checklist Pekerjaan Website Online Shop Laravel

## 1. Setup Project

- [V] Buat project Laravel baru
- [V] Setup koneksi database di `.env`
- [V] Install Laravel Breeze untuk login/register
- [V] Jalankan migration default Laravel
- [V] Setup Bootstrap 5 atau Tailwind CSS untuk tampilan mobile responsive
- [ ] Buat layout utama untuk customer
- [ ] Buat layout utama untuk admin/seller
- [ ] Tambahkan kolom `role` pada tabel `users`
- [ ] Buat middleware `admin`
- [ ] Batasi halaman admin hanya untuk user role `admin`

- [ ] Buat halaman pembayaran / payment page
- [ ] Tampilkan tombol bayar dengan Midtrans Snap
- [ ] Buat route callback/webhook Midtrans
- [ ] Buat `MidtransCallbackController`
- [ ] Verifikasi signature key dari Midtrans
- [ ] Simpan payload callback ke tabel `payments`
- [ ] Mapping status Midtrans ke status aplikasi
- [ ] Update `payment_status` order menjadi `paid` jika settlement/capture
- [ ] Update `order_status` menjadi `paid` jika pembayaran berhasil
- [ ] Update `paid_at` saat pembayaran berhasil
- [ ] Kurangi stok produk setelah pembayaran berhasil

- [ ] Tangani status `deny`
- [ ] Tangani status `failure`
